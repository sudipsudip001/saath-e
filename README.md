# saath-e

This is meant to be an agentic application that'll help people (specially old-aged) with their day to day technological chores and provide emotional support as well.

Since, most of us use mobile these days, this application is supposed to be a mobile application with voice support.

Our initial plan is to use React-Native and FastAPI endpoint as server. For ease of agentic capability using voice, Pipecat is proposed for now.

As we're working to promote use of Open source technology, the repository will exclusively make use of Open source models, tools, so that replication and improvement is possible by the community effort.


Motifs:
- To create a smoothly functioning mobile application with proper server that works as intended (to provide support technologically and emotionally to old age people or general users.)
- Proper use of agentic capabilities, best practices for agentic development and learning new ways to make agents effective.
- Learn the entire AI developmental toolkits from RAG, Web search, MCPs, agentic lifecycle and much more.


Proposed timeline:
Week 1: Create a working agent with tools available for most of the technological endeavors.
Week 1 1/2: Backend of the application
Week 1 1/2: Frontend of the applcation
Week 2: Added advanced tools that requires RAG and other advanced workflows.
Week 3: Memory and advanced workflows.
Week 4: Friend in-need completion and project wrap up.
